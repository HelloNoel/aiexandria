# AIexandria

AIexandria connects your AI assistant to documentation stored in Git
repositories. Ask about a topic, find the right source, and inspect the
documents behind the answer.

Start with [Getting started](getting-started.md). A new installation includes a
public collection and AIexandria help. You do not need to write an index or
publish a repository to try it.

- [Install and connect your client](installation.md).
- [Add your documentation](adding-documentation.md), including private
  repositories and docs you do not own.
- [Find information](source-discovery.md) and understand search results.
- [Prepare repositories](updating.md) before a session or on a schedule.
- [Enable ranked and global search](semantic-search.md).
- [Write useful indexes](writing-indexes.md).
- [Configure and troubleshoot](configuration.md).
- [Look up commands and tools](reference.md).

This guide describes **v0.4.0**. This release adds searches that remain
available during refreshes, repository updates, SHA-256 repository support, and
optional keyword, semantic and global passage search. It requires Git 2.43.7 or
newer.

Discovery and the public starter collection were introduced in v0.3.0. The
[v0.3.0 guide](https://github.com/HelloNoel/aiexandria/blob/v0.3.0/docs/getting-started.md)
remains available for that release.
