# AIexandria

AIexandria connects your AI assistant to documentation stored in Git repositories. Ask about a topic, find the right source, and inspect the documents behind the answer.

Start with [Getting started](getting-started.md). A new installation includes a public collection and AIexandria help. You do not need to write an index or publish a repository to try it.

- [Install and connect your client](installation.md).
- [Add your documentation](adding-documentation.md), including private repositories and docs you do not own.
- [Find information](source-discovery.md) and understand search results.
- [Write useful indexes](writing-indexes.md).
- [Configure and troubleshoot](configuration.md).
- [Look up commands and tools](reference.md).

This guide describes **v0.3.0**. Discovery and the default collection were added after v0.2.0. The [v0.2.0 guide](https://github.com/HelloNoel/aiexandria/blob/v0.2.0/docs/getting-started.md) remains available with that release's source; some historical hosting links refer to Codeberg.
